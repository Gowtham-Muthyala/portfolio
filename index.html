Pricing engine modernisation

UK insurer, via TCS, 2025

Problem

An actuarial pricing calculation needed to move from legacy tooling into a modern codebase that is quick to run and easy to test.

What I built

A Python engine using NumPy vectorisation and multiprocessing, with a hybrid design that keeps an Excel interface where actuaries need to see each step.

Result

30×faster, from 30 seconds to under 1

No-code calculation engine

Insurance clients, via TCS, 2021–2024

Problem

Setting up pricing logic for each new client needed developer time, so onboarding took weeks.

What I built

A client-agnostic engine where actuaries define calculation blocks in CSV or UI templates. A dependency-graph resolver works out the run order and isolates errors.

Result

1 hourto onboard a client, down from weeks
